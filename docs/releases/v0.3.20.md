# ClassSync 0.3.20

## Fixes

- Android Fireflies pushes now wake the background sync pipeline automatically instead of waiting for the user to open or tap the app.
- Cross-device or retry reconciliation is presented as a completed canonical summary instead of a user-facing duplicate failure.
- Completed Sync entries stay manageable: opening the row shows the job controls, while an explicit Library action opens the canonical summary.
- The Sync three-dot menu can change the class for completed summaries and can discard a transcript without deleting its published Notion summary.
- Changing a class refreshes the subject metadata of derived lecture tasks; discarding the transcript removes those derived tasks.
- A corrected class is now authoritative when a summary is regenerated, so conflicting class labels from the transcript or meeting metadata are not carried into the replacement summary.
- The in-app Library now preserves much more of the Notion presentation: rich inline emphasis and links, callout icons/backgrounds, code language, equations, quotes, to-do state, and text/background colors.
- Newly generated Notion summaries are visible immediately instead of being hidden inside collapsed `ClassSync generated` toggles.
- Legacy ClassSync toggle wrappers are migrated to visible content when the summary is opened or re-published by this version.

## Version

- Flutter version: `0.3.20+28`
